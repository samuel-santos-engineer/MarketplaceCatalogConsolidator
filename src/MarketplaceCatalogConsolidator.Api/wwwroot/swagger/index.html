Upload-to-catalog walkthrough

Start the local Development API and use Try it out in the operations below. Use only the configured API key; never put it in a URL.

  1. Call GET /api/v2/random-uuid for a fresh uuid. In POST /api/v1/uploads, set Idempotency-Key to it, provide X-Api-Key, select the JSON file as the single file part, and copy the uploadId from the 202 response.
  2. Call GET /api/v1/uploads/{uploadId}/status with that ID until upload.status is terminal and upload.reportAvailable is true. Inspect items and actionTaken.
  3. Call GET /api/v1/uploads/{uploadId}/report to download the final JSON report. If it returns 409, wait and retry the status step. Inspect summary and items.
  4. Call GET /api/v1/catalog, optionally filtering by sellerName or name, to see canonical products, seller offers, and totalCount.

The GET operations are public; only upload needs an API key. The sample input is artifacts/ProductEntry.json in the repository.
